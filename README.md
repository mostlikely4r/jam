# JAM

*Just another asteroid miner.*

![JAM](media/jam.gif)

Shoot asteroids. Collect the ore. Sell it at the station.

In development.

## Play

Play it in your browser at [mostlikely4r.github.io/jam](https://mostlikely4r.github.io/jam/), or run it yourself:

```
npm install
npm run dev
```

## Controls

| Key | |
|---|---|
| W | Thrust |
| Q / E | Rotate |
| Space | Fire |
| Esc | Pause and help |
